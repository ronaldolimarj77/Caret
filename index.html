Backup e Restauração (Completo)

O backup completo inclui TODOS os dados: pacientes, profissionais, especialidades, agendamentos, planos, estoque, eventos, pagamentos, configurações, tema, proteção e licenciamento.
Nome do arquivo: ThOne_<Dispositivo>_<ddmmaaaa>_<hhmmss>.json

Backup Incremental

O Backup Incremental salva apenas os dados novos ou alterados desde a última abertura do sistema (ou desde o último backup incremental). Ideal para envios rápidos e sincronização entre dispositivos.
Nome do arquivo: ThOne_INC_<Dispositivo>_<ddmmaaaa>_<hhmmss>.json

Carregando informações de referência...
Como funciona: o ponto de referência avança automaticamente a cada Backup Incremental. Ao restaurar, os dados são MESCLADOS com os existentes — registros novos são adicionados, e registros já existentes são atualizados se o backup for mais recente. Nada é sobrescrito em massa.

Proteção contra cópia do código-fonte

Defina usuário e senha para proteger contra visualização do código-fonte e abertura do DevTools. Quando a proteção está ativa, você precisa autenticar-se para alterar, desmarcar ou remover qualquer configuração de proteção.

Regras de segurança: com a proteção ativa, os campos ficam travados, o checkbox é desabilitado e qualquer botão (Salvar credenciais, Remover proteção) só funciona após autenticar.

Não foi possível baixar o arquivo automaticamente neste dispositivo. Copie o conteúdo abaixo e salve em um arquivo com o nome sugerido.

Como usar:
1. Toque em "Copiar JSON completo"
2. Abra o app de Notas do celular
3. Cole o conteúdo e salve como arquivo .json
4. Para restaurar, use Restaurar Backup Completo e selecione esse arquivo
